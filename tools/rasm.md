# El ensamblador

Este proyecto se ensambla con **rasm**, de Roudoudou.

No se incluye aquí porque es obra suya y tiene su propia licencia.
Descárgalo y compílalo desde el repositorio oficial:

    https://github.com/EdouardBERGE/rasm

En macOS:

    git clone --depth 1 https://github.com/EdouardBERGE/rasm.git
    cd rasm && make -f makefile.MacOS

Copia el binario resultante a `tools/rasm` y ya puedes usar los
scripts de este proyecto.
